# StoreShot — Acceptance & Verification Checklist

This document details the exact verification steps required to validate images generated by `storeshot` for Play Store and App Store listing submissions.

---

## 1. Automated Verification Checks

Run the automated test suite locally or in CI:

```bash
# 1. Verify code formatting and lint rules
flake8 src tests

# 2. Run unit and integration tests
pytest -v

# 3. Test example batch execution with JSON config
storeshot --config examples/input.json --overwrite
```

---

## 2. Image Asset Verification Matrix

| Verification Item | Specification Requirement | Verification Method |
|---|---|---|
| **JSON Root & Child Config** | Root defaults applied; child overrides honored | Verify `input.json` per-screenshot texts and colors |
| **File Names** | Exact match with input (`1.png` → `1.png`, etc.) | `ls examples/output` matches `ls examples/input` |
| **Output Dimensions** | `1080 × 1920` (or specified `--out-width` × `--out-height`) | `file examples/output/1.png` or PIL inspection |
| **Aspect Ratio** | Standard phone ratio (16:9 / 9:16 or custom) | Width / Height calculation |
| **Color Gradient** | Smooth transition from `bg-color-1` to `bg-color-2` | Inspect pixel colors at top/left vs bottom/right |
| **Inner Padding** | `pad-left`, `pad-right`, `pad-top`, `pad-bottom` respected | Screenshot centered inside inner bounds |
| **Corner Radius** | Antialiased rounded corners on screenshot | Pixel alpha at outer corners of screenshot is 0 |
| **Drop Shadow** | Blurred silhouette offset behind screenshot | Shadow gradient visibly spreads beneath device frame |
| **Stroked Rim** | Device stroke outline with `--screenshot-border-color` | Outline stroke rendered along curved silhouette |
| **Typography** | Maximum 2 lines; wraps and truncates with `...` | Second line does not overflow and ends in `...` if truncated |
| **JPEG Mode** | Opaque RGB canvas when `--format jpg` | Format is `JPEG` and mode is `RGB` (no alpha crash) |

## 3. Google Play Console Upload Validation

To confirm compliance with Google Play Store asset requirements:

1. **Format Check**:
   - Verify format is PNG or JPEG.
   - Verify file size is under 8 MB.

2. **Resolution Check**:
   - Standard phone screenshots: Minimum 1080px on shortest side; 16:9 or 9:16 aspect ratio (e.g. 1080×1920 or 1080×2400).
   - Verify DPI metadata is present (default 72 DPI).

3. **Visual Inspection in Console**:
   - Log in to [Google Play Console](https://play.google.com/console).
   - Navigate to **Store presence** → **Main store listing** → **Phone screenshots**.
   - Upload the generated PNG/JPEG files from `output/`.
   - Verify preview renders without distortion, cropping, or alpha channel errors.

---

## 4. Apple App Store Connect Validation

To confirm compliance with App Store Connect requirements:

1. **Resolution Check**:
   - iPhone 6.7" Display: `1290 × 2796` px (PNG/JPEG).
   - iPhone 6.5" Display: `1242 × 2688` px (PNG/JPEG).
   - iPad Pro 12.9" Display: `2048 × 2732` px (PNG/JPEG).

2. **RGB Profile**:
   - 72 DPI, sRGB or Display P3 color profile.
   - Flattened without transparent outer margins.
